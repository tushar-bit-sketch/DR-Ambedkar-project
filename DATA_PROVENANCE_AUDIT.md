## 4. Cryptographic Checksum & Immutability Verification

In compliance with OAIS AIP standards:
1. Every ingested master facsimile is hashed using `SHA-256` prior to database commit.
2. The generated hash is stored in the database `checksum` column and registered in the immutable `archival_files` ledger.
3. System endpoint `POST /api/v1/documents/{id}/verify-integrity` recomputes the file hash on demand and compares it against the stored manifest, guaranteeing that bit rot, accidental alteration, or malicious tampering is caught instantly.
